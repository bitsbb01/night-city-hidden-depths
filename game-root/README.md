# Installable payload

The first payload is a CET developer test scaffold located at:

`bin/x64/plugins/cyber_engine_tweaks/mods/night_city_hidden_depths/`

It tests door targeting/opening, the 25/65/10 encounter selection, and local JSON progress flags. It does not yet add authored building geometry, NPC/loot spawning, quests, or a production interaction hook. Read [the test guide](../docs/door-encounter-prototype.md) before using it in-game.

Add later release files here using their Cyberpunk 2077 install-relative paths. The release packaging script includes actual files below this folder and ignores this README.
